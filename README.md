## 🔥 О игре

**VOID SHOOTER** — вторая игра вселенной **CHAOS REALM**. Это хардкорный шутер с видом сверху, где каждый враг уникален:

- 👾 **Дрон** — телепортируется каждые 2 секунды и стреляет.
- 🦠 **Вирус** — преследует и взрывается при контакте.
- 👻 **Фантом** — невидим, пока не подойдёшь. Стрелять в него издалека нельзя!
- 👹 **ГЛИТЧ-БОСС** (каждая 5-я волна) — огромный, телепортируется, стреляет веером.

Между волнами появляются **стены данных**, которые блокируют путь и пули.

---

## ✨ Особенности

- 🎯 **Динамичный бой**: стрельба + рывок с неуязвимостью.
- 🌀 **Телепортация врагов**: никогда не знаешь, откуда ударят.
- 🧱 **Процедурные стены**: появляются и исчезают, меняя тактику.
- 📺 **Глитч-эффекты**: тряска экрана, сканлайны, случайные блоки.
- 📈 **Волновая система**: каждая волна сложнее предыдущей.
- 🔊 **Индустриальный звук**: синтез через Web Audio API.
- 📱 **Тач-поддержка**: базовое управление на телефоне.

## 🕹 Управление

| Клавиша | Действие |
|---------|----------|
| `WASD` / `Стрелки` | Движение |
| `Мышь` | Прицеливание |
| `ЛКМ` | Стрельба (зажать для автоогня) |
| `Пробел` | Рывок (дэш) с 1 сек кулдауном |
